# 프로젝트 도구체인은 활성화하되 프로비저닝하지 않는다

`mobile`은 프로젝트가 선언하고 호스트에 이미 설치된 Node·Ruby·JDK를 이번 실행에 비파괴적으로 활성화한다. 커밋된 도구 관리자 설정이 있으면 그것을 정본으로 사용하고, 설정이 없을 때만 현재 셸의 도구를 사용한다. 설정이 깨졌거나 trust되지 않았거나 필요한 버전이 없으면 조용히 fallback하지 않고 remediation과 함께 멈춘다.

`mobile up`은 `mise trust`, `mise install`, `mise use` 또는 Xcode·runtime 설치를 실행하지 않는다. `mise exec`는 기본적으로 누락된 도구를 자동 설치하므로 프로젝트 실행 환경은 `MISE_AUTO_INSTALL=false`를 강제한다. 이들은 사용자 동의가 필요한 도구 프로비저닝이다. 프로젝트 의존성은 활성화된 프로젝트 실행 환경에서 lockfile을 수정하지 않고 정렬하며, 앱 소스와 framework 버전을 바꾸는 마이그레이션은 범위 밖이다.

이 결정은 부모 셸에 우연히 잡힌 도구와 프로젝트 선언의 불일치를 없애면서도, 자동 설치 금지와 관측된 근거만 사용하는 ADR-0003·ADR-0005의 규율을 유지한다.
