# ADR-0014: 소스 공개는 Go 판정이 아니다

- 상태: 채택
- 날짜: 2026-10-05
- 관련: #130 · #131 · ADR-0008 · ADR-0011 (public 저장소 전환 부분 대체)

ADR-0011은 3/3 Go 전에 public 저장소 전환을 막았지만, 이 도구는 남의 프로젝트에서 build 도구를 실행하는 로컬 개발자 CLI라 사용자가 소스를 직접 확인할 수 있어야 신뢰를 얻는다. 저장소를 Apache-2.0 오픈소스로 공개하는 일을 Go 판정·정식 이름·외부 사용자 배포·일반적인 React Native 지원 주장과 분리하고, 소스 공개만 허용한다. 나머지는 ADR-0008의 세 repo 3/3 기준과 ADR-0011을 그대로 따른다.

## 결정

- 저장소를 Apache-2.0으로 공개할 수 있다. 저작권자는 maintainer 개인이다.
- README는 working name, pre-alpha, 현재 No-Go 판정, 지원 보증 없음, 신뢰 경계를 밝힌다.
- 바이너리 릴리스·패키지 배포, 정식 이름, Go 선언, 일반 지원 주장은 여전히 3/3 Go 전까지 하지 않는다.

## 대안

- **3/3 Go까지 private 유지**: 기각. 증거 기준과 무관한 소스 열람까지 막고, CI 비용이 private 과금에 묶인다.
- **새 public 저장소로 이전·history 재작성**: 기각. issue·PR로 남긴 결정 기록을 잃고, 보안 감사에서 공개를 막는 secret이 없었다. 커밋 메타데이터의 개인 이메일은 maintainer가 공개를 수용했다.

## 결과

- public 저장소에서는 GitHub-hosted standard runner CI를 무료로 쓴다.
- 현재 판정은 계속 **No-Go**다. 공개 사실을 Go·지원 근거로 인용하지 않는다.
- 공개 뒤 이슈와 PR 기록, Actions 로그도 공개되므로 증거 기록의 sanitized 규칙을 계속 지킨다.
