# ADR-0045: 가상 기기 출처를 사용자 단위 기록과 기기 identity로 판단한다

- 상태: 채택
- 날짜: 2026-10-22
- 관련: #186, #199, ADR-0041, ADR-0043

## 배경

실행 기기 목록은 실기기와 가상 기기, 켜짐과 부팅 필요를 구분한다. 그러나 가상 기기를 누가 만들었는지는 보여 주지 않는다. Xcode·Android Studio가 만든 Simulator·AVD와 승인된 환경 준비가 만든 것이 같은 목록에 같은 모양으로 나온다.
환경 준비 결과에는 `created`·`reused` 같은 출처가 있다. 하지만 준비할 때 한 번 출력될 뿐이다. 이후 기기 목록은 이를 읽지 않는다.
사용자 결정: 가상 기기 목록에 **기기 출처**(Runstir가 만듦·외부 기기·출처 불명)를 표시한다. 1.0 수용 기준에는 넣지 않는다.

## 결정

1. 승인된 환경 준비가 Simulator·AVD를 새로 만들고 생성 성공을 확인한 뒤에만 기록을 남긴다. 실패·취소한 생성과 재사용한 기기는 기록하지 않는다.
2. 기록은 사용자 계정마다 하나다. 모든 프로젝트와 worktree가 공유한다. 프로젝트 폴더에 두지 않는다. 기기는 프로젝트가 아니라 컴퓨터에 속하기 때문이다.
3. 같은 기기인지는 기기 identity로 판단한다.
   - iOS: Simulator UDID.
   - Android: AVD 이름, AVD 폴더 경로, 그 폴더의 생성 시각. 설정 변경(RAM 등)은 출처를 바꾸지 않는다. 같은 이름으로 다시 만든 AVD는 출처 불명이다.
4. 판단 결과:
   - 기록이 있고 identity가 일치하면 Runstir가 만듦.
   - 기록이 없으면 외부 기기. 이 기능 이전에 만든 기기도 외부 기기다. 이전 준비 결과나 이름으로 기록을 거꾸로 채우지 않는다.
   - 기록은 있지만 identity가 다르거나 확인할 수 없으면 출처 불명.
   - 기록 파일을 읽을 수 없으면 기록이 있었을 수 있는 가상 기기를 출처 불명으로 표시하고 doctor가 경고한다. Runstir는 그 파일을 자동으로 고치거나 덮어쓰지 않는다.
5. 기기는 만들었지만 기록을 쓰지 못하면 준비 결과를 부분 완료로 보고한다. 기기는 지우지 않는다. 그 기기는 외부 기기로 표시된다.
6. 지워진 기기의 기록은 남기되 표시하지 않고 자동 정리하지 않는다.
7. 기기 출처는 표시용이다. 기기 선택 순서·`down`·삭제 동작을 바꾸지 않는다. 프로젝트 실행 기기 목록, 앱 파일 기기 목록, CLI JSON·사람용 출력, GUI 기기 선택이 같은 값을 쓴다. Android 목록은 기준 AVD 폴더 경로를 함께 보여 주고 다른 폴더를 자동으로 합치지 않는다.

## 대안

- 이름 접두사(`Runstir-…`): 사용자가 이름을 바꾸거나 같은 이름으로 만들면 틀린다. 쓰지 않는다.
- 기기 안 표식: iOS Simulator에는 둘 곳이 없다. AVD 설정 파일에 쓰는 것은 기존 기기 보존 원칙과 맞지 않는다. 쓰지 않는다.
- AVD 설정 hash 비교: 사용자가 설정만 바꿔도 출처를 잃는다. 쓰지 않는다.

## 결과

- 사용자는 어떤 가상 기기가 Runstir 준비로 만들어졌는지 목록에서 바로 안다.
- 나중에 "Runstir가 만든 기기만 정리" 같은 기능이 이 기록을 근거로 쓸 수 있다. 그 기능의 계약은 이 ADR이 정하지 않는다.
- 기록 파일 형식과 identity 규칙은 이후 바꾸기 어렵다. 바꾸면 새 ADR로 이전 기록의 해석을 정한다.
