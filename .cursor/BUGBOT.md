# Runstir 보조 리뷰

Bugbot은 수동 보조 리뷰어다. 발견한 문제의 근거와 수정 제안을 남긴다.
코드 수정과 커밋은 로컬 에이전트가 맡는다. 병합 판단은 [PR 품질 절차](../docs/agents/review.md)를 따른다.

## 프로젝트 규칙

리뷰 전에 [코딩 규칙](../docs/coding-standards.md)과 [도메인 문서](../CONTEXT.md)를 읽는다.
변경이 다루는 결정은 관련 [ADR](../docs/adr/)에서 확인한다.
코딩 규칙의 직접 수정 절차는 로컬 에이전트에게 적용한다. Bugbot은 지적과 근거를 제공한다.

## 지적 기준

- 변경된 동작의 실제 결함과 요구사항 위반을 지적한다. 위치, 실패 조건, 영향을 설명한다.
- 테스트가 공개 interface와 실패 경로를 실행하는지 확인한다. 구현을 반복한 단언을 동작 검증으로 취급하지 않는다.
- 명령 실행, 경로, 승인, repository trust, lease를 바꾸면 입력 검증과 기존 실패 처리를 확인한다.
- 기록의 근거 범위를 확인한다. CI, 합성 테스트, MODEL-ONLY 근거를 실제 기기나 readiness의 증거로 승격하지 않는다.
- 스타일 취향과 무관한 리팩터는 지적에서 제외한다. 근거가 부족하면 추측 대신 불확실한 점을 명시한다.

리뷰를 위해 installer, 프로젝트 스크립트, 외부 명령을 실행하지 않는다.
비밀정보와 개인 경로의 민감한 내용을 코멘트에 포함하지 않는다.
